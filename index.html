Ta bibliothèque est enregistrée dans ton espace privé : seul ton compte (email + mot de passe) peut la lire ou l'écrire. Configuration une seule fois :
  1. console.firebase.google.com → ton projet → « Authentification » → « Commencer » → méthode « E-mail/Mot de passe » → activer.
  2. « Realtime Database » → onglet « Règles », remplace tout par : {"rules":{"users":{"$uid":{".read":"auth.uid === $uid",".write":"auth.uid === $uid"}}}} puis publie.
  3. Roue crantée → « Paramètres du projet » → onglet « Général » → copie la « Clé API Web ».
  4. Colle ci-dessous l'URL de la base, la clé API, puis crée ton compte (la 1re fois) ou connecte-toi (sur les autres appareils).
